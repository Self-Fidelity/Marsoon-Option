# Main 四状态期权数据口径

> 2026-09-05 定案。Main 只暴露四种状态；Go 的 `nearest/all` 仅为 Rust 与旧接口兼容保留。

| Main 名称 | API key | 合约范围 | 时间口径 | 存储 |
|---|---|---|---|---|
| 前日 EOD | `close` | 前一已完成 CME 交易日末仍未到期的合约 | 官方 final 结算价 + 官方 OI，估值锚为该日 Chicago 16:00 | 原 `option_strike_metrics_1m`（`basis=close`）、`option_market_state_1m`/`option_price_levels_1m`（`scope=close`） |
| 0DTE | `0dte` | 到期日等于当前 CME 交易日 | 盘中分钟快照 | 原三张分析表，`scope=0dte` |
| 30DTE | `d30` | `0 ≤ DTE ≤ 30`，包含 0DTE | 同一分钟盘中分钟快照聚合 | 原状态/价位表，`scope=d30`；执行价基础数据仍按真实到期日存储 |
| 90DTE | `d90` | `0 ≤ DTE ≤ 90`，包含 0DTE/30DTE | 同一分钟快照聚合 | 原状态/价位表，`scope=d90`；执行价基础数据仍按真实到期日存储 |

## 约束

- 前日 EOD 严格使用当前 CME 交易日前一个已完成交易日；周一回看周五，周末闭市时也回看周五。当天即使提前出现 final 记录，也不得进入前日 EOD。
- EOD、0DTE、30DTE、90DTE 都复用现有表，不创建重复快照表。OI、GEX、Delta、Charm 是同一快照的仓位结构，不跨分钟相加。
- Main 的 `OptionScope` 不接受 `all`。旧本地布局里的 `all/RTH` 加载时迁移为 `d90`。
- Go 继续计算/存储 `nearest/all`，只供 Rust 终端和旧 API 使用；Main 不查询、不展示。
