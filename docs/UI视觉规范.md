# UI 视觉规范

> 2026-09-05 起生效。目标：纯黑期权数据终端、暖橙品牌强调、清晰的深灰层级。

## 字体

- UI：`--ms-font-ui`，用于标题、导航、按钮、下拉框和说明文字；标题 13–14px/700，主要控件 11–13px/600。
- 数据：`--ms-font-data`（Tailwind `font-mono`），只用于价格、时间、执行价、指标读数和代码；表格主数据 11–13px，图内辅助字 9–10px。
- 禁止在普通按钮和导航中新增等宽字体；禁止组件自行声明另一套 font-family。

## 颜色

- 页面与图表使用 `--ms-app-bg` / `--ms-plot-bg`；面板层使用 `--ms-panel-bg`，卡片与浮层使用 `--ms-card-bg`。
- 品牌与选中态统一 `--ms-brand` 暖橙；品牌按钮使用黑字。上涨/Call 使用 `--ms-buy*`，下跌/Put 使用 `--ms-sell*`。
- 组件只引用 `--ms-*` 变量；新增颜色先进入 `globals.css`，不在业务组件散落十六进制色值。

## 组件层级

- 页面功能栏 70px；一级控件高 40px，面板工具控件 28–32px。
- 面板圆角 12px、控件圆角 10px、面板边框 1px `--ms-separator`。
- 通用控件使用 `.ms-control`，浮层使用 `.ms-popover`，橙色主操作使用 `.ms-primary`。
- 行情图不绘制装饰性背景网格；坐标轴、零轴和真实参考线按需要保留。
