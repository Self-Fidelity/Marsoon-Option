# UI 视觉规范（Marsoon 期权看板）

> 2026-09-05 起生效。2026-09-10 由原《UI视觉规范》（强制规范）与《Marsoon-UI 风格参考》（完整参考）**合并为本文件**：
> 第一节是必须遵守的硬约束，第二~八节是完整色值/字号/尺寸/控件/布局规范，第九节是对外转发的说明，第十节是整理依据。
> 目标：**近黑色金融数据终端 —— 深灰分层、品牌黄强调、紧凑排版、清晰的数据语义。**

---

## 一、硬约束（写代码时必须遵守）

- **字体分工**：UI 用 `--ms-font-ui`（标题、导航、按钮、下拉框、说明文字）；数据用 `--ms-font-data`（Tailwind `font-mono`，只用于价格、时间、执行价、指标读数、代码）。
  - 禁止在普通按钮和导航中新增等宽字体；禁止组件自行声明另一套 font-family。
- **颜色来源**：组件只引用 `--ms-*` 变量；**新增颜色先进入 `src/app/globals.css`**，不在业务组件散落十六进制色值。
- **层级取值**：页面/图表用 `--ms-app-bg` / `--ms-plot-bg`；面板用 `--ms-panel-bg`；卡片与浮层用 `--ms-card-bg`。
- **语义色**：品牌与选中态统一 `--ms-brand`（品牌黄，实心按钮用近黑文字）；上涨/Call 用 `--ms-buy*`；下跌/Put 用 `--ms-sell*`。
- **控件样式**：通用控件 `.ms-control`、浮层 `.ms-popover`、主操作 `.ms-primary`、面板 `.ms-panel` —— 扩展时优先复用同一套。
- **图表**：行情图**不绘制装饰性背景网格**；坐标轴、零轴和真实参考线按需要保留。
- **空态**：无数据一律用 `—` 或带原因的空态文案，**不使用模拟数值或零值填充**。

## 二、整体视觉方向

- 页面以近黑背景为底，面板、卡片、浮层逐层提亮，通过细边框区分结构。
- 品牌黄集中用于品牌、选中状态和主要操作；图表的红、绿、蓝承担具体数据含义。
- 信息密度较高，导航与工具栏克制，主要空间留给图表和表格。
- 界面容器采用适度圆角；图内矩阵、数据条、价位标签可用直角或小圆角。
- 文字以小字号和中等偏粗字重建立层级，避免依靠大标题占据数据空间。
- 阴影低调，主要用于区分面板和浮层；交互以颜色变化、短过渡为主。

| 含义 | 常规色 | 强调色 / 图表色 |

## 四、字体风格

### 4.1 UI 字体：现代无衬线

用于标题、导航、按钮、下拉框、说明文字。项目声明优先级：

```text
Inter, ui-sans-serif, -apple-system, BlinkMacSystemFont,
"Segoe UI", "PingFang SC", "Microsoft YaHei", Arial, sans-serif
```

中文通常由系统中文字体承接（苹方 / 微软雅黑）。当前主应用未配置字体文件加载；Inter 只是字体栈首选名称，实际显示取决于设备可用字体 —— 需要跨设备完全一致时应额外提供字体资源。

### 4.2 数据字体：等宽、等宽数字

用于价格、时间、执行价、指标读数和代码。项目字体栈：

```text
"SFMono-Regular", "Roboto Mono", "Cascadia Code",
Menlo, Consolas, monospace
```

数据类同时设置 `font-variant-numeric: tabular-nums` 和 `letter-spacing: 0`，让数字列整齐、数值更新时宽度稳定。

### 4.3 基础排版

- 全局根字号：**14px**；全局字距 `-0.01em`（略收紧）。
- 数据字距 `0`；少量英文表头会额外拉开字距。
- 常规内容以 400–500 字重为基础；按钮和导航常用 600，标题和强读数常用 700。

## 五、字号体系

辅助字号较小，适合桌面密集看板，不宜直接作为长文阅读字号。

| 场景 | 字号 | 常用字重 | 字体 |
| --- | --- | --- | --- |
| 页面、面板标题（规范） | 13–14px | 700 | UI 无衬线 |
| 侧栏导航 | 13px | 600 | UI 无衬线 |
| 顶栏主要操作 | 12px | 600 | UI 无衬线 |
| Dock 窗口标签 | 12px | 600 | UI 无衬线 |
| 面板按钮、下拉框 | 10–11px（规范范围 11–13px） | 600 | UI 无衬线 |
| 表格主要行情数字 | 11–13px（期权链主单元格 12px） | 普通或强调 | 等宽 |
| 表格 CALL / PUT 分组标题 | 13px | 700 | 等宽 |
| 图内坐标、图例、辅助读数 | 9–10px | 400–600 | 多数等宽 |
| 日内图原生坐标文字 | 11px | 图表默认 | 继承 UI 字体栈 |
| 注释、次级元信息 | 8–9px | 400–600 | 按信息类型区分 |
| 极窄图表、紧凑标记 | 局部 7–8px | 按面板设置 | 局部密度适配 |

表格主数据右对齐；价格与执行价保留必要精度。重要数值优先通过文字色、字重和空间位置突出。

## 六、尺寸、圆角与间距

### 6.1 设计规范尺寸

| 元素 | 规范值 |
| --- | --- |
| 页面功能栏高度 | 70px |
| 一级控件高度 | 40px |
| 面板工具控件高度 | 28–32px |
| Dock 标签栏高度 | 36px |
| 面板圆角 | 12px |
| 标准控件圆角 | 10px |
| 浮层圆角 | 12px |
| 内嵌分段按钮、紧凑图例圆角 | 常见 7–8px |
| 面板、控件边框 | 1px |

### 6.2 当前实现的尺寸换算

项目根字号 14px，Tailwind 间距单位 `0.25rem`，因此部分工具类的实际 CSS 尺寸小于设计目标。**对外做新稿用规范尺寸；复刻当前实现用下表换算。**

| 当前类名 | CSS 尺寸 |
| --- | --- |
| `h-10`（顶栏按钮） | 35px |
| `h-8`（部分面板控件） | 28px |
| `h-7`（部分面板控件） | 24.5px |
| `h-6`（内嵌周期选项） | 21px |
| `w-52`（展开侧栏） | 182px |
| `gap-1 / gap-2 / gap-3 / gap-4` | 3.5 / 7 / 10.5 / 14px |
| `p-2.5 / px-3` | 8.75 / 10.5px |

显式声明的 `70px`、`12px` 圆角与 `text-[12px]` 等不受根字号换算影响。

## 七、控件和交互状态

- **普通控件**：近黑底、1px 灰边框、10px 圆角；悬浮时背景提亮、边框更明显。
- **选中控件**：16% 透明度黄底、黄色文字、约 65% 透明度黄边框。
- **主操作**：实心品牌黄底、近黑文字、700 字重；悬浮变更亮的黄。
- **键盘焦点**：2px 黄色轮廓，透明度约 42%，外偏移 2px。
- **禁用状态**：降低透明度，常见 40%–60%。
- **浮层**：深灰底、细边框、12px 圆角，阴影 `0 18px 48px rgb(0 0 0 / 58%)`。
- **通用面板阴影**：`0 12px 30px rgb(0 0 0 / 24%)`；Dock 窗格主要依靠背景和边框分层。
- **图标**：Lucide 线性图标；面板常见 12–13px，导航 15px / 1.5px 描边。
- **动效**：控件用颜色过渡；侧栏 200ms ease-out 宽度与滑移过渡。尊重系统"减少动态效果"设置。
- **滚动条**：细样式，深灰滑块配面板色轨道。

## 八、布局与图表风格

### 8.1 页面结构

- 桌面端：左侧窄导航 + 顶部功能栏 + 主体多窗口看板。
- 品牌标识为品牌黄圆角方块中的黑色字母 M。
- 导航保持简短，主入口为「面板 / 投教」。
- 顶栏保留侧栏开关、品种、面板与模板入口，以及有数据时的现价。
- 看板窗口可拼装、可调尺寸；Dock 激活标签顶部有 2px 黄色标记。
- 小屏使用底部导航，面板内容按可用空间降低信息密度。

### 8.2 图表与表格

- 绘图区近黑，数据线、柱体、价位和数值成为视觉主体。
- 行情图不加装饰性背景网格；坐标轴、零轴和真实参考线按需要保留；表格与热力图保留结构分隔。
- Call / Put 用绿红语义，Spot 用蓝色，Flip 用黄色。
- 热力图以色阶表达量级，配合图例、悬浮读数和选中描边。
- 表格用细分隔线、紧凑行距、等宽数字和右对齐；图内标签可用直角或小圆角。
- 窄窗口优先减少刻度、辅助列和标签数量，绘图区吸收尺寸变化；局部面板有辅助字号降档。
- 普通面板控制溢出；期权链、热力图等长内容按面板需要滚动。
- **无数据使用 `—` 或带原因的空态，不使用模拟数值或零值填充。**

## 九、可直接转发的设计说明

> 请参考 Marsoon 的深色金融终端风格：页面底色 #050505，面板 #0D0D0D，卡片与浮层 #141414，边框 #292929；品牌色为品牌黄 #FFD21E。主文字为暖白 #F7F5F2，次级文字 #AAA6A0。界面文字使用 Inter / 系统无衬线字体，行情数字使用系统等宽字体并保持数字等宽。根字号 14px，标题 13–14px，主要按钮 11–13px，表格数据 11–13px，图内辅助字 9–10px。面板圆角 12px，标准控件圆角 10px，采用细边框和克制阴影。设计目标为 70px 顶栏、40px 一级控件、28–32px 面板控件。整体紧凑、清晰、数据优先；品牌黄用于品牌与选中状态，绿涨红跌，蓝色标记现价。通过深灰层级、字重和留白建立秩序。
