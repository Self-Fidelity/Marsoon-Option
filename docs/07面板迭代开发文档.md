# 07 波动率微笑偏斜迭代开发文档

## 2026-09-05：X 轴标签自适应

执行价 X 轴不再固定最多显示 20 个标签。面板按 `useMeasureSize` 实测绘图区宽度，并结合格式化后最长执行价文本估算最小标签间距；窄窗自动减少标签，宽窗自动恢复，始终保留首尾刻度且不改变曲线数据与坐标映射。

共享算法 `axis-label-density.ts` 同步用于 10 期限结构的 DTE 轴：宽窗最多 5 个标签，窄窗自动降密度并保留近远端。

## 2026-09-08：四周期曲线叠加

- 前日 EOD、0DTE、30DTE、90DTE 从单选改为复选叠加，最多同时显示四档且至少保留一档。
- 首次点击周期后，波动率窗口使用自己的 scopes，不修改全局周期或其他 widget。
- scope 固定按 `0DTE → 30DTE → 90DTE → 前日EOD` 排序；第一条有效曲线为主线，其余按既有虚线和透明度规则叠加。
- 多周期选择进入布局存档，刷新和模板恢复后继续保留。

## 2026-09-08：叠加周期线型图例

- 周期使用固定线型：0DTE 实线、30DTE 长虚线、90DTE 点线、前日 EOD 点划线；主周期仅加粗，不再改变线型。
- Call/Put 继续使用绿/红，形成“颜色=期权方向、线型=周期”的双编码。
- 底部每个周期显示真实 SVG 线型样本、周期名和线型名；主周期追加“主”，无数据周期灰显。
- 合约名称不再重复占据底部图例宽度，保留在周期项的 hover title 中。
