## 一、本轮改动（第三十四轮）

### A 级（正确性）

- **A1 列级 CW/PW/FLIP**：model 层对每个到期列独立求 CW（该列 call_gex 最大档）/PW（|put_gex| 最大档）/FLIP（net 沿价格符号过零，线性插值估价位，无过零则无）；列内有效格 <3 不计算不画。面板在对应格的列内右缘画小标记：CW 绿三角 ◀、PW 红三角 ◀、FLIP 琥珀短竖线（`--ms-brand`）。顶部全局 chips 保留并标注"当前周期口径"。
- **A2 TERM Σ 跟随 mode**：列加总按当前 net/call/put 口径（put 保留后端负号），不再恒 net。
- **A3 截断提示**：model 返回 `truncatedExpirations`/`truncatedStrikes`；列超 7 在 TERM Σ 区末端标"+N 期"，行超 25 在行轴底标"+N 档"，不再静默截断。

### B 级（交互）

- **B4 hover 升级**：格子 hover 时同行/同列微亮（brightness 1.35）、当前格琥珀内描边；矩阵右上角固定读数卡（执行价 × 到期日期+DTE、Call/Put/Net 三值 formatNotional、`quality_flags&1` → "IV 为回退估算"白话）。原生 title 的裸 quality_flags 数字已移除。
- **B5 点击下钻联动**：新建 `board-focus-store.ts`（`{strike?, expiry?, at} | null` + `setFocus`/`clearFocus`，TTL 30s）。05 点行权价标签或格子 → `{strike}`；点列头 → `{expiry}`。
  - 09 消费：`OptionsChainPanel` 订阅 focus.expiry，命中本窗到期 tabs 则切换并 2s 琥珀 ring 高亮，找不到不动；自有到期选择语义不变。
  - 08 消费：`GexBreakdownPanel` 订阅 focus.strike，最接近档画 2s 琥珀描边框。
  - 消费侧统一 `liveFocus` 过期判断（at+30s 忽略），`focusHandledAtRef` 防重复处理。
- **B6 窄窗 LOD**（useMeasureSize 实测宽，chrome 固定 px、行高 ROW_H 不动）：

  | 实测宽 | 档位 | 行为 |
  |---|---|---|
  | ≥640 | full | 全量：列头日期小字 + 全部 chips + 图例 |
  | 420~640 | mid | 砍列头日期小字；SPOT→S、FLIP→F 缩写 |
  | 280~420 | compact | 行数降 13（锚点档必含）；TERM Σ 只留条不标数字；隐藏页脚图例 |
  | <280 | barsOnly | 只留色块矩阵 + 全局墙框 + 现货/Flip 线；行轴、chips、TERM Σ、列头全隐 |

- **B7 全局归一化色阶**：maxAbs 改为 net/call/put 三口径一起取全局最大（model 层 `maxAbs`），切 tab 颜色深浅可比；页脚加红→透明→绿渐变图例条（两端标 ±max 的 formatNotional，注明 0 居中）。

### C 级（顺手）

- **C8** `buildExpirationHeatmapModel` 调用处加 useMemo（`panel-wrappers.tsx` 新增 `ExpirationHeatmapView`）。
- **C9** 面板级质量告警：view-model `hasQualityWarnings` 透传 model，chips 行加琥珀小字"⚠ 部分档位 IV 为回退估算"。
- **C10** 服务端 payload 裁剪（按 spot 远近预筛）留待以后，已在 `expiration-heatmap-model.ts` 注释注明。

## 三、第三十五轮（2026-09-04）：hover 跟随鼠标 + 标志白话 + 数值开关

- 读数卡从矩阵右上角固定改为**跟随鼠标**（容器级 mousemove 记相对坐标，近右/下边自动翻边，卡片宽 192、高按 ~150 估算翻边阈值）。
- 标志解释进 hover：格上有列级标记时读数卡附白话（`MARK_EXPLAIN`：绿◀=该到期 Call Wall/上方压力，红◀=该到期 Put Wall/下方支撑，琥珀▎=该到期 Gamma Flip）；顶部 CW/PW/SPOT/FLIP chips 也补了 title 一句话解释。
- 新增「数值」开关（视图 tabs 右侧）：开则格内显示当前口径 GEX 数值（8px + 底色描影保证可读）；compact/barsOnly 档强制不显示。
- 格级 onMouseLeave 移除，hover/mouse 统一由矩阵容器 onMouseLeave 清空（防抖交给 React state 同值跳过）。

### 第三十八轮（2026-09-04）：左轴多周期共振文字标签 + 直角化对齐 06

需求口径：多周期共振的 wall/flip/spot 要在左 Y 轴用**文字标签**展现（第三十六轮的 glyph 图标列方案"小白看不懂"，作废）；05 风格整体与 06 对齐——全部直角框；格子 hover 只许改边框风格，交叉高亮逻辑（filter brightness / inset boxShadow）一律不动。

- **数据接线**：05 从 `TableDashWindow` 拆出独立 `ExpirationWindow`（08 骨架不动）。有效 scopes = 联动 ? 标的级多选数组 : 解耦冻结单值，用 `useOptionsDashboardMulti` 并发取数；矩阵本体仍只消费主周期（scopes[0]，与 `effectiveTableScope` 同口径），close 空态/isPending/has_data 守卫保留；全部非 close 且有数据周期各出一条 `ScopeKeyLevels` 传给 `buildExpirationHeatmapModel(vm, scopeLevels)`（第三十六轮已留的第二参数本轮接上）。
- **左轴共振标签**：删除半成品 glyph 方案（`GutterGlyph`/`SCOPE_SHORT`/`SCOPE_NAME`/`GUTTER_MARK_TEXT`/`GUTTER_COL_W` 全清）。命中逻辑不变（容差 1.5 tick），输出改为按类型分组：每行每类型（CW/PW/FLIP/SPOT）合并为一张直角 chip，成员 scope 按 06 固定序 `0dte>d30>d90>all` 排序，名字复用 06 `badgeName`（如 `0D+90·CW`、`RTH·FLIP`、`SPOT`）。chip 对齐 06 徽标：直角、`var(--ms-panel-bg)` 不透明底、3px accent 竖条语义色（cw=success / pw=danger / flip=brand / spot=key-gamma）、名字 9px/700；hover 用 `title` 给 06 同款白话（`LEVEL_BADGE_EXPLAIN`+`SCOPE_PREFIX_EXPLAIN`，import 不复制）。
- **布局**：行轴列宽 64 → `64 + gutterW`（gutterW 按最长标签名 5.4px/char 估算，上限 110，无标记时保持原视觉）；chip 在行权价左侧竖排，ROW_H 28 约束下每行最多 2 张，超出按 CW>PW>FLIP>SPOT 取舍；列头"行权价"、底部"+N 档"、TERM Σ 左侧占位同步新宽度。共振档（同类型 ≥2 周期命中）行权价数字提亮加粗（`resonanceTypes` 保留）。
- **直角化**：热力图格子、墙行框、窗外锚点贴边标记的 `rounded-[3px]` 全部去掉；格子 hover 的 brightness/inset boxShadow 逻辑零改动；列头按钮 `rounded-sm`、hover 读数卡等不动。
- 验证：`npx tsc --noEmit` 通过。

### 第三十九轮（2026-09-04）：SPOT 改为轴上数字（对齐 06），FLIP 吸附修复

需求口径：SPOT 不需要徽标 chip，模仿 06 在 Y 轴实际价位处放纯数字即可。

- **SPOT 移出 gutter chip**：`GutterMarkType` 收窄为 cw/pw/flip，`GUTTER_KIND`/`GUTTER_COLOR`/`GUTTER_TYPE_ORDER` 删 spot 项；行轴新增绝对定位 SPOT 数字（`top: spotY`，与矩阵区现货虚线同一 y），对齐 06 plain 变体——无底色牌、`--ms-key-gamma` 语义色纯文字 10px/700，title 一句话解释；与行权价数字撞车（行中心距 spotY < 9px）时只隐藏该行权价数字（06 刻度碰撞同口径），点击下钻保留。
- **FLIP 命中修复**：FLIP 是插值连续价位，1.5 tick（NQ=0.375pt）容差相对 5pt 档距几乎永不命中（同第三十八轮 SPOT 不显示的根因），改为吸附到窗口内最近档（`nearestStrike`）；墙是真实执行价，保持 1.5 tick 精确容差防窗外误标。
- 验证：`npx tsc --noEmit` 通过。

## 四、恢复最近 0DTE 热力图显示（2026-09-07）

- 根因：周末当前 0DTE 为空时，dashboard 回退候选把更新时间更晚的 `nearest` 状态与 `0dte` 混合排序，最终用 Sunday nearest 时间查询 0DTE surface，响应仍为空。
- 修复：dashboard 历史回退只选择相同 scope 的最新状态；K线自己的时间锚点仍允许在没有 0DTE 状态时使用 nearest，两个数据域不再共用错误的回退语义。
- 数据口径不变：热力图只消费 `dashboard.heatmap.cells/levels`，使用同一 snapshot minute，不跨分钟求和、不造数；过期交易日通过明确的 09/04 列展示。
- 验证：本地 dashboard 返回 NQU6 `snapshot_unix=1788551880`、393 cells、10 levels；页面实际显示 1 个 0DTE 列、81 个现价附近执行价，虚拟窗口渲染 41 行。TypeScript 和 13 项热力图模型/视口测试通过。

## 五、不透明线性色带（2026-09-09）

- 到期热力图使用共享 `heatmap-color-scale` 的 256 色 RGB 查表：非零绝对值 P95 为数量上限，线性归一化后查询颜色，达到或超过上限统一命中最热端。
- 删除平方根提亮和 `color-mix` 动态着色；正值使用绿系多节点色带，负值使用红系多节点色带。
- 每个格子使用单个不透明纯色，透明度固定为 1；格子之间不做渐变插值、滤镜或模糊。
