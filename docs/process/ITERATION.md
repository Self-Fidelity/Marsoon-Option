## 一、当前迭代主题：读链路治理

数据源已单一化为 Go 期权服务。当前主要矛盾不在"有没有数据"，而在**取数可靠性**：
后端 TTFB 仅 2~6s（计算正常），但响应体无压缩慢传（175KB 以 1~3KB/s 传，极端时卡死 150s+），
撞上 BFF 12s 硬超时即出现空态。完整定位见 [`../backend/服务端优化与更新策略.md`](../backend/服务端优化与更新策略.md)
与 [`../frontend/本地侧优化方案.md`](../frontend/本地侧优化方案.md)。

### P0（本仓可自主落地）

1. **BFF 总预算超时 + 错误分层文案**（本地侧 L3）——把"每次 upstream 12s"改为"整条路由一个预算"
   （dashboard 25s / levels、intraday 35s）；错误分三类（超时 / 真无数据 / 陈旧），
   且**靠错误码而非 message 字符串传递**（`data-messages.ts` 的清洗正则会吞掉含 timeout/fetch 的原文）。
2. **缓存分级 + 陈旧兜底**（L4 + L2）——成功值 + 上次成功时间戳；上游失败且未超陈旧上限时返回旧值 +
   `stale` 标记，前端显示"数据可能不是最新"而不是白板；加 5s 负缓存防抖。
3. **underlying 解析缓存 + 面板并发闸门**（L5 + L6）——每请求少一次往返；同 product 最多 2 路并发打上游。

### P1（需 Go 侧配合，收益最高）

4. **开启 gzip / br 压缩**——d90/close 从 ~900KB 降到 ~100KB，是唯一能把 55~150s 请求压回个位数秒的改动。
5. **预序列化 + Content-Length**——现在只有 `Transfer-Encoding: chunked` 且传输中会 stall，
   高度怀疑序列化与写网络耦合；先 `Marshal` 到 `bytes.Buffer` 再一次性写。
6. **快照级响应缓存 + ETag(304)**——d30/d90 每 5 分钟才变，却每请求重新序列化 900KB。

### P2

7. **前端显示缓冲**（L8）——保留上次成功数据、空态加手动重试。
8. **`days` 参数对齐 scope 默认值**（L9，纯口径一致性，非性能项）。
9. **响应裁剪 / levels 分页降采样**（L7）——涉及数据契约，单独评审后再做。
10. **后端清理 `/options/status` 陈旧重复条目**（实测 `GC/nearest` 长期残留一条 20 小时前的快照）。

## 二、已定决策（仍然有效）

- **周期五档**：`close | 0dte | d30 | d90 | all`；`all` 显示名 RTH。总控多选、至少 1 个，
  优先级 `0dte > d30 > d90 > all > close`，`[0]` 为主周期。
- **更新节奏（实测）**：`0dte`/`nearest` **60s**、`d30`/`d90`/`all` **300s**、`close` **每日一次**。
- **K 线粒度 1 分钟**；期货近 24h 约 1500 根/品种。
- **删除 Net GEX `Δ5m/Δ15m/Δ30m`** 指标（细节指标不做）。
- **缺数据显示空态**：一律 `null` + `missing_reason`，严禁 0 填充、不造数。
- **墙口径是 GEX 加权（OI×gamma）**，与"纯 OI 最大"不是同一件事；如需双显另议。
- **gamma flip 取距现货最近的变号点**（不是区间低端第一个变号点），修复 0DTE flip 漂到 call wall 之上的 artifact。
- **0DTE T 地板 0.35 天**，theta 不做额外截断（换算在展示层）。
- **05/08 窗口策略**：锚点（现货/CW/PW/FLIP 所在档）必含 + 按距现货填充至 25 档；
  锚点出窗时画贴边标记。

## 三、面板已知问题

- **08 GEX 拆分**：只渲染现货附近约 11 档，墙线仅在窗口内绘制——GC 这类 spot 与双墙距离较大的品种，
  两墙会同时不可见。现由"锚点必含 + 贴边标记"策略覆盖，仍需实测确认。
- **05 热力图**：行轴曾截断 13 档丢墙，已改 25 档 + 窗外贴边标记。
- **09 期权链**：`chain.rows` 的 `last`/`oi`/`volume`/`change` 大量 null（后端原始行情层缺失），
  前端保持 `—`，不降级为 0；涨跌幅待后端提供昨收字段。
- **10 月间价差**：BCR 槽位占位（当前数据源无主动方判定），`iv_official` 恒 null（官方无结算 IV），
  UI 应隐藏该线而非显示 0。
- **收盘档**：三品种 `state: partial`，属后端 EOD 未完整发布，面板保持空态。
