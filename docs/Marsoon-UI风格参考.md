# Marsoon UI 风格参考

> 对外参考版 · 2026-09-05  
> 根据 Marsoon Options 主应用的全局样式、视觉规范和看板组件整理。适用于设计稿、前端实现及同风格产品参考；独立投教 iframe 内的页面不在本稿范围内。

## 1. 整体视觉方向

**近黑色金融数据终端：深灰分层、黄色品牌强调、紧凑排版、清晰的数据语义。**

- 页面以近黑背景为底，面板、卡片、浮层逐层提亮，通过细边框区分结构。
- 黄色集中用于品牌、选中状态和主要操作；图表的红、绿、蓝承担具体数据含义。
- 信息密度较高，导航与工具栏克制，主要空间留给图表和表格。
- 界面容器采用适度圆角，图内矩阵、数据条、价位标签可以使用直角或小圆角。
- 文字以小字号和中等偏粗字重建立层级，避免依靠大标题占据数据空间。
- 阴影低调，主要用于区分面板和浮层；交互以颜色变化、短过渡为主。

| 用途 | 色值 | 项目变量 |
| --- | --- | --- |
| 页面背景 | `#050505` | `--ms-app-bg` |
| 绘图区背景 | `#060606` | `--ms-plot-bg` |
| 图表背景备用层 | `#070707` | `--ms-chart-bg` |
| 输入框、普通控件底色 | `#0A0A0A` | `--ms-input-bg` |
| 面板背景 | `#0D0D0D` | `--ms-panel-bg` |

| 更高层背景、图标悬浮底色 | `#1B1B1B` | `--ms-elevated-bg` |

背景的层级变化很小，以亮度差建立深度。整体为黑灰体系，文字灰略带暖色。

实心黄色按钮使用近黑文字 `#090603`。普通选中控件可用半透明黄底、黄字和黄色边框；导航选中项使用黄边框、浅黄底、主文字色。

### 行情与状态语义

| 含义 | 常规色 | 强调色 / 图表色 |

## 3. 字体风格

### UI 字体：现代无衬线

用于标题、导航、按钮、下拉框、说明文字。项目声明的字体优先级为：

```text
Inter, ui-sans-serif, -apple-system, BlinkMacSystemFont,
"Segoe UI", "PingFang SC", "Microsoft YaHei", Arial, sans-serif
```

中文通常由系统中文字体承接，例如苹方或微软雅黑。当前主应用未配置字体文件加载，Inter 是字体栈首选名称，实际显示取决于设备可用字体；需要跨设备完全一致时，应额外提供字体资源。

### 数据字体：等宽、等宽数字

用于价格、时间、执行价、指标读数和代码。项目字体栈为：

```text
"SFMono-Regular", "Roboto Mono", "Cascadia Code",
Menlo, Consolas, monospace
```

数据类同时设置 `font-variant-numeric: tabular-nums` 和 `letter-spacing: 0`，让数字列整齐、数值更新时宽度稳定。普通导航和操作按钮按规范使用 UI 字体。

### 基础排版

- 全局根字号：**14px**。
- 全局字距：`-0.01em`，略微收紧。
- 数据字距：`0`；少量英文表头会额外拉开字距。
- 常规内容以 400–500 字重为基础；按钮和导航常用 600，标题和强读数常用 700。

## 4. 字号体系

以下结合项目规范与组件中的显式字号整理。辅助字号较小，适合当前桌面密集看板，不宜直接作为长文阅读字号。

| 场景 | 字号 | 常用字重 | 字体 |
| --- | --- | --- | --- |
| 页面、面板标题（规范） | 13–14px | 700 | UI 无衬线 |
| 侧栏导航 | 13px | 600 | UI 无衬线 |
| 顶栏主要操作 | 12px | 600 | UI 无衬线 |
| Dock 窗口标签 | 12px | 600 | UI 无衬线 |
| 面板按钮、下拉框 | 10–11px，主要控件规范范围 11–13px | 600 | UI 无衬线 |
| 表格主要行情数字 | 11–13px，期权链主单元格 12px | 普通或强调字重 | 等宽 |
| 表格 CALL / PUT 分组标题 | 13px | 700 | 等宽 |
| 图内坐标、图例、辅助读数 | 9–10px | 400–600 | 多数为等宽 |
| 日内图原生坐标文字 | 11px | 图表默认 | 当前继承 UI 字体栈 |
| 注释、次级元信息 | 8–9px | 400–600 | 按信息类型区分 |
| 极窄图表、紧凑标记 | 局部 7–8px | 按面板设置 | 属于局部密度适配 |

表格主数据采用右对齐，价格和执行价保留必要精度。重要数值优先通过文字色、字重和空间位置突出。

## 5. 尺寸、圆角与间距

### 设计规范尺寸

| 元素 | 规范值 |
| --- | --- |
| 页面功能栏高度 | 70px |
| 一级控件高度 | 40px |
| 面板工具控件高度 | 28–32px |
| Dock 标签栏高度 | 36px |
| 面板圆角 | 12px |
| 标准控件圆角 | 10px |
| 浮层圆角 | 12px |
| 内嵌分段按钮、紧凑图例圆角 | 常见 7–8px |
| 面板、控件边框 | 1px |

### 当前实现的尺寸换算

项目根字号为 14px，Tailwind 默认间距单位为 `0.25rem`，因此部分工具类的实际 CSS 尺寸小于上述设计目标。对外制作新设计稿可使用规范尺寸；复刻当前实现时应使用下列换算。

| 当前类名 | CSS 尺寸 |
| --- | --- |
| `h-10`（顶栏按钮） | 35px |
| `h-8`（部分面板控件） | 28px |
| `h-7`（部分面板控件） | 24.5px |
| `h-6`（内嵌周期选项） | 21px |
| `w-52`（展开侧栏） | 182px |
| `gap-1 / gap-2 / gap-3 / gap-4` | 3.5 / 7 / 10.5 / 14px |
| `p-2.5 / px-3` | 8.75 / 10.5px |

显式声明的 `70px`、`12px` 圆角与 `text-[12px]` 等不受根字号换算影响。间距整体紧凑，同组控件距离小，不同内容区用边框与适当留白区分。

## 6. 控件和交互状态

- **普通控件**：近黑底、1px 灰边框、10px 圆角；悬浮时背景提亮，边框更明显。
- **选中控件**：16% 透明度黄底、黄色文字、约 65% 透明度黄边框。
- **主操作**：实心品牌黄底、近黑文字、700 字重；悬浮变为更亮的黄色。
- **键盘焦点**：2px 黄色轮廓，透明度约 42%，外偏移 2px。
- **禁用状态**：降低透明度，具体组件常见 40%–60%。
- **浮层**：深灰底、细边框、12px 圆角，阴影为 `0 18px 48px rgb(0 0 0 / 58%)`。
- **通用面板阴影**：`0 12px 30px rgb(0 0 0 / 24%)`；Dock 窗格主要依靠背景和边框分层。
- **图标**：使用 Lucide 线性图标；面板常见 12–13px，导航为 15px、1.5px 描边。
- **动效**：控件使用颜色过渡；侧栏采用 200ms ease-out 宽度与滑移过渡。尊重系统减少动态效果设置。
- **滚动条**：细样式，深灰滑块配面板色轨道。

项目通用样式对应 `.ms-panel`、`.ms-control`、`.ms-popover`、`.ms-primary`；扩展时优先复用同一套样式与颜色变量。

## 7. 布局与图表风格

### 页面结构

- 桌面端为左侧窄导航、顶部功能栏、主体多窗口看板。
- 品牌标识为黄色圆角方块中的黑色字母 M。
- 导航保持简短，主入口为「面板 / 投教」。
- 顶栏保留侧栏开关、品种、面板与模板入口，以及有数据时的现价。
- 看板窗口可拼装、调整尺寸；当前 Dock 激活标签顶部有 2px 黄色标记。
- 小屏使用底部导航，面板内容按可用空间降低信息密度。

### 图表与表格

- 绘图区为近黑色，数据线、柱体、价位和数值成为视觉主体。
- 行情图按规范不加装饰性背景网格；坐标轴、零轴和真实参考线按需要保留，表格与热力图保留结构分隔。
- Call / Put 使用绿红语义，Spot 使用蓝色，Flip 使用黄色。
- 热力图以色阶表达量级，配合图例、悬浮读数和选中描边。
- 表格使用细分隔线、紧凑行距、等宽数字和右对齐；图内标签可采用直角或小圆角。
- 窄窗口优先减少刻度、辅助列和标签数量，绘图区吸收尺寸变化；局部面板有辅助字号降档。
- 普通面板控制溢出，期权链、热力图等长内容按面板需要滚动。
- 无数据使用 `—` 或带原因的空态，不使用模拟数值或零值填充。

## 8. 可直接转发的设计说明

> 请参考 Marsoon 的深色金融终端风格：页面底色 #050505，面板 #0D0D0D，卡片与浮层 #141414，边框 #292929；品牌色为亮黄 #FFD21E。主文字为暖白 #F7F5F2，次级文字 #AAA6A0。界面文字使用 Inter / 系统无衬线字体，行情数字使用系统等宽字体并保持数字等宽。根字号 14px，标题 13–14px，主要按钮 11–13px，表格数据 11–13px，图内辅助字 9–10px。面板圆角 12px，标准控件圆角 10px，采用细边框和克制阴影。设计目标为 70px 顶栏、40px 一级控件、28–32px 面板控件。整体紧凑、清晰、数据优先；黄色用于品牌与选中状态，绿涨红跌，蓝色标记现价。通过深灰层级、字重和留白建立秩序。

## 9. 整理依据

本稿基于项目文件核对，未进行浏览器像素测量。规范与现有实现存在局部尺寸、字体例外，已在上文区分。

- `docs/UI视觉规范.md`：正式视觉方向与组件规范。
- `src/app/globals.css`：色值、字体栈、全局排版、公共控件和 Dock 主题。
- `src/app/layout.tsx`：主应用样式与字体接入方式。
- `src/components/Sidebar.tsx`：导航、品牌标识、图标和动效。
- `src/features/board/BoardAddMenu.tsx`、`BoardTemplateMenu.tsx`、`WindowToolbar.tsx`：控件字号与间距。
- `src/features/board/OptionsChainPanel.tsx`、`ExpirationHeatmapPanel.tsx`、`IntradayPanel.tsx`：表格、热力图与日内图的文字和数据视觉。
- `node_modules/tailwindcss/theme.css`：当前 rem 间距换算依据。
