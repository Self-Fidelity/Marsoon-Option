## 1. 领域模型：Gamma 双链路框架（首页那张图）

产品的全部内容长在一个框架上。**两条链同源于 Γ，并列关系，不是上下游**。

```
L0 输入变量      标的价格 S        隐含波动率 IV        剩余时间 T
                   │ΔS                │IV变动             │时间流逝
L1 希腊引擎     DELTA Δ  ←── Γ决定Δ ──  GAMMA Γ(核心) ── ∂Γ/∂t ──→  COLOR
                                         │
                    ┌────────────────────┴────────────────────┐
              机制链 MECHANICS                          读图链 MAP READING
              对冲量 = Γ×ΔS×合约数                     Γ 按行权价摊开取特征点
                   │                                       │
              Dealer 机械对冲                        Call Wall / Put Wall
              卖出期权→保持Δ中性→被迫买卖             Gamma Flip / Pin Risk
                   │                                       │
              正Γ区: 买跌卖涨·压波动·均值回归    ──反馈──→  读图预判 Dealer
              负Γ区: 追涨杀跌·放大波动·趋势加速           会在哪踩刹车
```

必须守住的核心认知（首页文案沉淀，改动需慎重）：

- 做市商对冲是**约束不是选择**：被迫的交易比自愿的交易更好预测。
- **墙不是对冲的原因，而是对冲留下的痕迹**。用地图找位置，用机制找动作。
- 其他希腊字母管**定价**（慢），这套框架管**流量**（快），日内交易赚快的部分。
- Γ 越接近到期越大（COLOR 管这件事），所以 0DTE 是日内波动的主角。

## 4. 数据口径（业务红线）

初稿 footer 明确记录，属于业务决策不是技术细节：

- 当前口径 = **美股 Dealer GEX**（SpotGamma 体系）：GEX = 每股Γ × OI × 100 × S，符号假设为"客户买 call / 买 put，Dealer 对手方"。
- **落地 A 股必须改回持仓 GEX 并翻转符号假设**——这是一次业务口径切换，技术上只应触动 core 计算层（见技术架构第 3、7 节），面板与教学叙事不动。
- 正负Γ区的行为含义（正=均值回归/负=趋势加速）随口径一起翻转，文案集中在 core 层输出，不要散落在各面板里。

## 5. 视觉与交互规范

**主题：全面采用 Marsoon ClassicDark / Marsoon Tide**（用户确认，初稿的纯黑 #000 配色作废）。以 Marsoon 仓 `src/app/globals.css` 的 `--ms-*` 语义变量为准，**不在组件里新增近似色**：

| 语义（我们的业务含义） | Marsoon 变量/色值 |
|---|---|
| 正Γ / 支撑 / call 侧 | Buy/Positive `#18D5B5` |
| 负Γ / 阻力 / put 侧 | Sell/Negative `#FF5A70` |
| Γ 核心 / **Gamma Flip** / 重点标注 | Brand 金 `#FFD21E`（Marsoon 规矩：品牌金只用于选中、Gamma Flip 和重要交互——正好扣住我们的翻转线） |
| 机制链 / Key Gamma / 中性信息 | Key Gamma 蓝 `#32AAFF` |
| 背景 / 面板 / 卡片 / 图表底 | `#0F0F0F` / `#1C1C1E` / `#2C2C2E` / `#0C0C0C` |
| 主文字 / 次要文字 | `#F2F2F2` / `#9A9A9E` |

**Marsoon 造型规矩**（照抄执行）：Panel 圆角 10px、Button/Input 8px、Panel 内边距约 12px；细分隔线 + 轻阴影构建层级；买卖色不与成功/失败色混用；**避免玻璃拟态、霓虹渐变、大光晕和常见 AI Dashboard 风**。初稿的"3px 左色条 + 极淡底"卡片造型可保留为面板内卡片变体，但色值一律换成上表。

**布局**：看板 Dockview 分窗（dockview-react）；360px 移动端不横向溢出、排版降级为单列（继承 Marsoon 验收线）。

**全局交互**：导航收敛两项（/board 拼装看板、/teaching 教学看板）路由切换；教学为独立页（功能栏 + 整页 iframe），无 Esc/覆盖层退出；侧栏全站统一、可收起（开关在各页功能栏）；**看板实时接后端 API 更新**——初稿的"单文件离线"只是草稿容器形态，不是产品要求。
